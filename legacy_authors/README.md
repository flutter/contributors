# Legacy AUTHORS Archive

Historically, Flutter repositories maintained static `AUTHORS` files listing individual contributors for copyright and recognition purposes. Over time, maintaining separate text files across dozens of repositories proved difficult to keep up-to-date and provided no visibility into active permissions or governance roles.

With the adoption of the [Flutter Contributor Ladder](../docs/LADDER.md), the `flutter/contributors` repository is now the authoritative source of truth for all Flutter contributor roles and permissions, published dynamically in [ROSTER.md](../ROSTER.md).

This directory archives historical `AUTHORS` files to honor every contributor who helped build Flutter:
- `flutter.AUTHORS`: Historical AUTHORS list from `flutter/flutter`.
- `packages.AUTHORS`: Historical AUTHORS list from `flutter/packages`.
- `website.AUTHORS`: Historical AUTHORS list from `flutter/website`.
- `devtools.AUTHORS`: Historical AUTHORS list from `flutter/devtools`.
